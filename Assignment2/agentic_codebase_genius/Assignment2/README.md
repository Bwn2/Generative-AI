# Codebase Genius 🧠

An AI-powered multi-agent system that automatically generates high-quality documentation for software repositories.

## Features

- 📁 Automatic repository cloning and structure analysis
- 📖 README summarization  
- 🔍 Code parsing and relationship mapping
- 📚 Comprehensive markdown documentation generation
- 🎯 Support for Python and Jac codebases
